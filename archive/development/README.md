# Development records

These source-text records preserve implementation reviews and their supporting
evidence. Their statements, counts and paths describe the development state
at the time each record was written. They are not instructions for using the
package or statements about its present behavior.

- `VERIFICATION.md.txt`: detailed verification chronology and protocol evidence.
- `ALGORITHM_REVISION_PLAN.md.txt`: algorithm implementation work plan.
- `REVIEW_REVISION_PLAN.md.txt`: numerical and evaluation review work plan.

[MANIFEST.json](MANIFEST.json) records each source path, stored path, byte count
and SHA-256 digest. Text contents are preserved verbatim, including relative
paths and links that refer to their original locations. Use the
[algorithm contract and validation](../../VERIFICATION.md) and
[README](../../README.md) for the supported API and commands.
