# Reference figures

These six PNGs are retained reference figures. In particular, the "Theory
Validated!" and 25% breakdown annotations in `breakdown_validation.png` are not
supported as a universal guarantee for the default uncapped TER estimator.

See the [archive explanation](../README.md) for interpretation and provenance,
the [file inventory](../MANIFEST.json) for hashes, and the
[statistical interpretation](../../VERIFICATION.md#statistical-interpretation)
for the qualification. The [archive guide](../README.md) links the
figure-generation scripts for new measured results.
